## 탄산 샘플러 Tansan-Sampler
물리 성도 시뮬레이션의 일부 요소를 차용해 스펙트럼 포락과 비주기성 조정으로 성도 시뮬레이션을 흉내내는, WORLD-Based (Open)UTAU용 리샘플러 TanSan-Sampler(탄산샘플러, 약자 TSampler)의 저장소입니다.
>**모든 코드는 AI로 작성되었으며, 인간이 검토 및 수정을 마쳤습니다.**

----
### 플래그 설명

| 플래그 | 범위 | 기본 | 값 방향 | 효과 |
|---|---:|---:|---|---|
| `g` | -100~100 | 0 | `+` 굵어짐 / `-` 얇아짐 | 젠더 플래그. 전체 톤의 성별감이 바뀜. `+`는 두껍고 낮아지고, `-`는 얇고 높아짐. |
| `Bi` | 0~100 | 50 | 증가 | 고역 존재감이 증가해 더 밝고 또렷해짐. 낮추면 둥글고 어두워짐. |
| `Hu` | -100~100 | 0 | `+` 브라이트 / `-` 허스키 | `+`는 선명하고 깨끗한 톤, `-`는 약간 낮고 쉰 듯한 허스키 톤. |
| `Mo` | -100~100 | 0 | `+` 입 열림 / `-` 입 닫힘 | `+`는 입을 크게 여는 느낌, `-`는 입을 좁힌 먹먹한 발화 느낌. |
| `Tn` | -100~100 | 0 | `+` 긴장 / `-` 이완 | `+`는 힘 준 발성(단단함), `-`는 힘 뺀 발성(부드러움). |
| `t` | -1200~1200 | 0 | `+` 상승 / `-` 하강 | 음정을 센트 단위로 올리거나 내림. |
| `Gr` | 0~100 | 0 | 증가 | 중고역대의 거친 질감을 강조해 그로울 보이스와 유사한 질감을 줌. |
| `Vg` | 0~100 | 0 | 증가 | 유성 구간에만 낮은 맥동과 throat rasp가 추가되어 더 growl답게 들림. Gr 플래그와 동시 사용 추천 |
| `Vtl` | -100~100 | 0 | `+` 길게 / `-` 짧게 | F1은 비교적 보존하고 F2/F3 간격과 고역 공간감을 비선형으로 조정. |
| `Vtr` | -100~100 | 0 | `+` 전진 / `-` 후퇴 | F2/F3 중심을 더 직접적으로 이동. |
| `Vtw` | -100~100 | 0 | `+` 집중 / `-` 확산 | 포먼트 위치보다 폭/Q를 조정. |
| `Vc` | 0~100 | 0 | 증가 | 협착/twang, 2~5kHz 밀도와 주기성을 올림. |
| `Nn` | -100~100 | 0 | `+` 비성 / `-` 비성 억제 | `+`는 콧소리/비강 공명에 가까운 느낌으로 가공됨, `-`는 비성 느낌을 줄여줌. |
| `Hr` | 0~100 | 70 | 70 기준 증감 | 70보다 올리면 배음이 살아나 음성이 또렷해지고, 내리면 노이즈 같은 거친 질감이 추가됨. |
| `N` | -100~100 | 0 | `+` 추가 / `-` 억제 | `+`는 거칠기/노이즈 증가, `-`는 배경 노이즈 감소. |
| `Bh` | -100~100 | 0 | `+` 추가 / `-` 억제 | `+`는 숨소리 증가, `-`는 숨소리가 줄어들어 건조하고 또렷한 발성. |
| `Ns` | -100~100 | 0 | `+` 밝게 / `-` 어둡게 | 노이즈 톤 색깔만 바뀜. `+`는 고역대 강조, hiss 성향, `-`는 탁하고 어두운 노이즈 성향. |
| `Ln` | -100~100 | 15 | `+` 강화 / `-` 완화 | 노트 간 음량 정규화 강도. `+`는 볼륨 편차를 줄여 일정하게, `-`는 정규화 정도를 줄여 원본 다이내믹을 더 보존. |
| `Lp` | 0~2 | 1 | 선택 | 긴 노트의 스트레치/루프 방식 선택. `0` 스트레치, `1` 정방향 루프, `2` ping-pong/mirrored loop. (`Lp0`도 너무 길면 자동으로 미러 루프를 섞음.) |
| `Cw` | -100~100 | 0 | `+` 강화 / `-` 약화 | 자음/연결부의 볼륨과 포먼트 성향을 같이 조정. |
| `Vw` | -100~100 | 0 | `+` 강화 / `-` 약화 | 모음부의 볼륨과 포먼트 성향을 같이 조정. |
| `Rv` | 0~1 | 0 | 선택 | 적용된 노트를 역재생함. `1` 전체 역재생, `0` off. |
| `Vo` | -100~100 | 0 | `+` 유성 / `-` 무성 | `+`는 AP를 줄이고 배음을 주입, `-`는 무성 성분을 늘림. `-100`은 F0도 끊음. |
| `Fc` | -1~1 | 0 | 선택 | `1` 하이컷, `-1` 로우컷. 렌더 파이프라인 가장 마지막에 적용. |
| `Eb` | 0~100 | 0 | 증가 | 최종 노트 2/3 지점부터 페이드아웃하면서 숨소리 성분을 추가. 짧은 노트에서는 자동으로 더 두드러지게 적용. |
| `Fh`/`Ft` | 0~100 | 0 | 증가 | Fh 노트 앞부분/ Ft 노트 끝부분에 보컬프라이와 유사한 효과를 추가함.|
| `Tm` | 0~100 | 0 | 증가 | 주기적 피치 흔들림. 값별로 주기와 깊이가 같이 달라짐. |
| `Ds` | 0~100 | 0 | 증가 | 디스토션 효과 |
| `Bc` | 0~100 | 0 | 증가 | 비트크러셔 효과 |
| `Vz` | 0~7 | 0 | 선택 | 보컬라이저 포먼트 필터. `1` 아, `2` 에, `3` 이, `4` 오, `5` 우, `6` 어, `7` N. |
| `VzS` | 0~100 | 100 | 증가 | 보컬라이저 강도. `Vz` 선택은 그대로 두고 적용량만 조절. |
